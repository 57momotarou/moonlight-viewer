Moonlight Viewer（iPhone閲覧専用）

必要ファイル:
index.html
app.js
style.css
config.js
manifest.json
sw.js
icons/icon-192.png
icons/icon-512.png

GitHub Pagesで公開後、初回アクセス時に「接続設定」から
Supabase URL と Publishable key を入力できます。
Secret key / service_role は絶対に入力しないでください。

viewerアカウントのメールアドレスとパスワードでログインしてください。
このWeb版にはデータ更新・削除処理は実装していません。
